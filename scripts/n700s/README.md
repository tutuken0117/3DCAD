# N700S 1 号車（見本モデル）の車内の組み立て

`samples/models/n700s-latest.3dcadz`（アプリの「?model=n700s-latest」）の車内のうち、
運転室・前後のデッキ・化粧室・洗面所を作り直すスクリプトです。アプリ本体の動作には関係しません。

- `lib.py` … 頂点・辺・面を足す道具（箱・円柱・回転体・パイプ・7 セグメント数字・IPA ゴシックの文字）
- `shell.py` …（いまは使っていない。R24 で試したが実車と違う形になったため、外板は R23 までのものを使う）車体の外板を数式で作り直す試作（先頭長 10.7 m の先頭形状、運転台の盛り上がりと左右の翼の面、肩のエッジ、前面窓と縁取り、前照灯、青帯の先頭部、ドアの継ぎ目、号車・行先表示、排障器、台車の開口、平らな側面に窓の穴）
- `exterior.py` … 外装の手直しの試作（R26: くちばしを広げる、R27: 前面窓の柱を外し短くする）。どちらも R23 より実車から遠くなったため使わない。外装は R23 のまま
- `bogie.py` … 台車（R23 までの外板の台車の開口に収める。直径 860 mm・フランジ付きの車輪、踏面がレール頭の中心 z=±0.75 で高さ 0 に接する。車軸・軸箱・軸ばね・台車枠・空気ばね・ヨーダンパ・ブレーキディスク・ATC 受電器）
- `check_shell.py` … 室内などの部品が新しい外板の内側に収まっているかを、外板の式で調べる
- `cab.py` … 運転室（馬蹄形の運転台、3 面の計器盤と液晶、右手のマスコン 13 ノッチ・左手のブレーキ、逆転ハンドル、運転士の椅子など）
- `lav.py` … 後ろのデッキ・化粧室（男女共用・女性用・男性用）・洗面所・貫通扉、前のデッキ
- `saloon.py` … 客室の窓の日よけ（ロールカーテン）、窓下のテーブル、床とカーペットの色、後ろの妻面の幌
- `track.py` … 線路（東海道新幹線の複線のバラスト軌道・PC まくらぎ・60 kg レール）、高さ 1 m の盛土、ケーブルのトラフ、架線柱と架線
- `build.py` … もとのモデル（R18）の古いグループを消して作り直し、R28 として書き出す
- `check_inside.py` … 新しい部品が車体の外へ出ていないかの目安（車体の形によっては当てにならない。最後は外観の画像で確認）

## 作り方

```
pip install fonttools
git show 4c09a72:samples/models/n700s-latest.3dcadz > r18.3dcadz
python3 scripts/n700s/build.py r18.3dcadz samples/models/n700s-latest.3dcadz
```

液晶画面は、アプリの材料「液晶画面・表示灯（lcd-*）」を使う（光るが、プレゼン表示の室内の明かりにはしない）。

## 参考にしたこと

報道・乗車記などの公開情報（マスコンは右手・ブレーキは左手の 2 ハンドル、N700S のマスコンは 13 段、
速度計に ATC の許容速度を緑の丸で表示、化粧室は男女共用におむつ交換台・女性用にベビーチェア、
洗面台は人感センサーで鏡の脇の明かりが明るくなる、デッキに防犯カメラ）。
計器盤の画面の中身・スイッチの並び・寸法などの細部は推定で作っており、実物どおりではありません。
